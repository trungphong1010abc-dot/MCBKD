# Hướng dẫn test DHT22

## Wiring

| DHT22        | ESP32    |
| ------------ | -------- |
| `+` / VCC    | `3V3`    |
| `-` / GND    | `GND`    |
| `OUT` / DATA | `GPIO27` |

Các chân nên dùng cho DHT22:

GPIO4, GPIO5, GPIO13, GPIO14, GPIO16, GPIO17,
GPIO18, GPIO19, GPIO21, GPIO22, GPIO23,
GPIO25, GPIO26, GPIO27, GPIO32, GPIO33
